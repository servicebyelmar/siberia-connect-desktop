<h1 align="center">Siberia Connect для Windows</h1>

<p align="center">Быстрый VPN в одну кнопку. Своё приложение — без сторонних клиентов и ручной настройки.</p>

## Что умеет

- ❄️ **Одна кнопка** — нажми на снежинку, и подключение защищено
- ✨ **Без регистрации** — открыл приложение, нажал на снежинку, и всё работает: аккаунт и пробный день создаются сами
- 🔑 **Вход** через Telegram или по коду доступа `SC-XXXXX-XXXXX`; аккаунт из приложения можно связать с Telegram (трей → «Связать с Telegram»)
- 🧭 **Понятный статус** — если подписка закончилась, приложение так и скажет и откроет тарифы
- 🇷🇺 **Российские сайты и банки — напрямую**, мимо VPN: быстрее и без капчи
- ⚡️ **Северное Сияние (Авто)** — приложение само проверяет все серверы через туннель и подключает к самому быстрому; если сервер перестал пропускать трафик — переключает
- 🌍 **Ручной выбор сервера** — для тех, кто хочет сам
- 🚀 **Автозапуск** с Windows и автоподключение
- 🧊 **Значок в трее** — VPN работает, даже когда окно закрыто
- 🔒 Работают только ключи Siberia Connect
- 🪟 **Стекло Windows 11** — Mica или Acrylic (значок в трее → «Оформление окна»)
- 💾 **Резервная копия настроек** — файл `.scbackup`, зашифрован паролем (AES-256-GCM)
- 🛟 **Защита от сбоев** — если приложение упало, интернет вернётся сам: прокси Windows и адаптер «Весь компьютер» убираются автоматически

## Установка

Скачай установщик на странице [sibirapp.duckdns.org/app/dl](https://sibirapp.duckdns.org/app/dl/) или в боте [@SibirConnectBot](https://t.me/SibirConnectBot).
Права администратора не нужны. Windows 10 и 11 (64-бит).

## Поддержка

[@SibirHelpBot](https://t.me/SibirHelpBot) · канал новостей и статуса серверов — в приложении, раздел «Профиль».
